# Evaluation Rubric

Use automatic evaluation as a screening tool, not as proof of literary quality.

## Dimensions

### Level Fit

Check:
- sentence length;
- complex grammar;
- vocabulary burden;
- kanji/furigana burden;
- annotation density;
- jReadability if available.

Typical issues:
- too many long modifiers;
- target level used only as a vague label;
- N1 version made artificially harder;
- N3 version made childish.

### Fidelity

Check:
- must-keep events retained;
- causal order retained;
- no invented explanation;
- no over-summary;
- QA-based fidelity if possible.

Typical issues:
- source scene compressed into plot outline;
- psychological movement omitted;
- relation nuance changed;
- hidden future information revealed early.

### Coherence

Check:
- names and aliases;
- character relations;
- timeline;
- terms preserved consistently;
- Story Bible constraints.

Typical issues:
- `先生` replaced inconsistently;
- a character knows something too early;
- symbolic term deleted in one scene and restored later.

### Literary Tone

Check:
- point of view;
- character voice;
- rhythm;
- ambiguity;
- silence and aftertaste;
- natural Japanese.

Typical issues:
- explanatory textbook tone;
- all ambiguity converted into direct explanation;
- cultural atmosphere removed;
- mechanical short sentences.

### Learning Support

Check:
- annotations are short and learner-facing;
- cultural terms are supported;
- notes do not over-explain interpretation;
- annotation count is not excessive.

## Suggested Scores

Use 1-5 for each dimension:

1. unusable;
2. serious problems;
3. acceptable draft;
4. strong with minor issues;
5. publication-ready after light editing.

Report limitations when no human evaluation is performed.
